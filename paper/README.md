# Preprint

Source for:

> Anton Künzi, *One Edge, Unbounded Instability: Hilbert Decomposition Signed
> Measures in Multiparameter Persistence*, preprint, version 1.0
> (30 July 2026).

Compile with a current [Tectonic](https://tectonic-typesetting.github.io/)
installation:

```bash
cd paper
tectonic -X compile main.tex
```

`one-edge-unbounded-instability.pdf` is the compiled paper checked for
layout. The release repository is
[`ZeterMordio/one-edge-instability`](https://github.com/ZeterMordio/one-edge-instability).
The Zenodo DOI and exact release commit will be inserted before public release.

The canonical front page uses a modern left-aligned preprint header.
`variants/option-1a.tex` provides a compact journal-style alternative with
the author metadata beneath the author, while `variants/option-1b.tex` places
the same metadata in an author footnote. Both wrappers reuse the complete text
of `main.tex`.
