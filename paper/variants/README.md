# Front-page variants

The canonical manuscript, `../main.tex`, uses the modern left-aligned preprint
treatment previously shown as option 2.

- `option-1a.tex` uses the same title treatment but keeps the affiliation and
  contact metadata in two restrained lines below the author.
- `option-1b.tex` uses a compact journal-style title block with affiliation,
  ORCID, and email in an author footnote.

Both entry points include the canonical manuscript body, so the mathematical
content cannot drift between previews.
